# CamCare Frontend

React + Vite frontend for CamCare dashboard/admin.

## Requirements

- Bun (recommended) or Node.js 20+

## Quick Start

1. Install deps:

```bash
bun install
```

2. Configure API base URL (optional):

Create `.env` with:

```bash
VITE_API_URL=http://127.0.0.1:5050
```

3. Run dev server:

```bash
bun run dev
```

Default URL:

- [http://127.0.0.1:5173](http://127.0.0.1:5173)

## Build

```bash
bun run build
```
